# The Law Office of Isa Abdur-Rahman, PLLC

Website for The Law Office of Isa Abdur-Rahman, PLLC — Real Estate, Business
Law, and Family Estates, serving New York since 2004.

Built with [Next.js 14](https://nextjs.org/) (App Router, TypeScript).

## Pages

- **Home** — firm overview and practice areas
- **Attorney Bio** — background of Isa Abdur-Rahman, Esq.
- **Contact** — office address, phone, fax, and email

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploying

Deploys on [Vercel](https://vercel.com/) with zero configuration — every push
to `main` triggers a build and deploy.
